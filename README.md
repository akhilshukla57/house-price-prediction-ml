# 🏠 House Price Prediction ML

A machine learning project that predicts house sale prices using property features such as overall quality, living area, basement area, garage information, and year built.

The project follows a complete machine learning workflow from data exploration and preprocessing to model training, evaluation, and feature importance analysis.

---

## 📌 Project Overview

The goal of this project is to build a machine learning model capable of predicting house sale prices based on historical housing data.

The project uses the well-known Kaggle House Prices dataset containing **1,460 houses and 81 features**.

The workflow includes:

- Data exploration and understanding
- Missing value analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Outlier detection and handling
- Feature encoding
- Machine learning model training
- Model comparison
- Model improvement
- Feature importance analysis
- Final model evaluation
